Settings

To open the Settings window, choose Settings... from the menu of the menu bar icon or the Dock icon. Click General or Registration in the toolbar to switch tabs.

This page describes the General tab. For the Registration tab, see Registering Apps to Stop Scrolling In.

Directions to Stop

Choose which directions to stop when scrolling is stopped.

Vertical Only
Stops only vertical scrolling. You can still scroll horizontally.
Horizontal Only
Stops only horizontal scrolling. You can still scroll vertically.
Both
Stops both vertical and horizontal scrolling. This is the default.

This setting is used when All Apps is selected in Stop Scrolling In. Newly registered apps also start with this setting.

Note For registered apps, you set the directions to stop for each app in the Registration tab (see Choosing the directions to stop for each app). Changing the directions to stop in the General tab doesn’t change apps that are already registered.

Display Mode

Choose where Mouse Scroll Toggle appears: Menu Bar Only, Dock Only, or Menu Bar and Dock. The default is Menu Bar and Dock.

On a Mac whose built-in display has a notch, Menu Bar Only isn’t available, because the menu bar icon could become hidden behind the notch and you wouldn’t be able to use it.

Tip If you can’t find the menu bar icon, hold down Command while opening Mouse Scroll Toggle to reset Display Mode to the default (Menu Bar and Dock).

Launch at Login

When this is on, Mouse Scroll Toggle opens automatically when you log in to your Mac.
