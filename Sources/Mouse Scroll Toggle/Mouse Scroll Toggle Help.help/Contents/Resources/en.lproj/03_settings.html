Settings

To open the Settings window, choose Settings... from the menu of the menu bar icon or the Dock icon. Click General, Scrolling, or Registration in the toolbar to switch tabs.

This page describes the General and Scrolling tabs. For the Registration tab, see Registering Apps to Stop Scrolling In.

General Tab

Set where Mouse Scroll Toggle appears and how it opens.

Display Mode

Choose where Mouse Scroll Toggle appears: Menu Bar Only, Dock Only, or Menu Bar and Dock. The default is Menu Bar and Dock.

On a Mac whose built-in display has a notch, Menu Bar Only isn’t available, because the menu bar icon could become hidden behind the notch and you wouldn’t be able to use it.

Tip If you can’t find the menu bar icon, hold down Command while opening Mouse Scroll Toggle to reset Display Mode to the default (Menu Bar and Dock).

Launch at Login

When this is on, Mouse Scroll Toggle opens automatically when you log in to your Mac.

Scrolling Tab

Set which directions to stop and how to temporarily override the stop.

Directions to Stop

Choose which directions to stop when scrolling is stopped.

Vertical Only
Stops only vertical scrolling. You can still scroll horizontally.
Horizontal Only
Stops only horizontal scrolling. You can still scroll vertically.
Both
Stops both vertical and horizontal scrolling. This is the default.

This setting is used when All Apps is selected in Stop Scrolling In. Newly registered apps also start with this setting.

Note For registered apps, you set the directions to stop for each app in the Registration tab (see Choosing the directions to stop for each app). Changing the directions to stop in the Scrolling tab doesn’t change apps that are already registered.

Temporary Override

Lets you scroll while holding the modifier keys you choose, even when scrolling is stopped.

Scroll While Holding Modifier Keys
When this is on, you can use Temporary Override. It’s on by default.
Modifier Keys
Choose the keys to use for Temporary Override: command, option, shift, control, ⌥⌘, ⇧⌘, or ⌥⇧⌘. The default is command.
Note You can scroll only while you’re holding exactly the keys you chose. For example, if you choose ⌥⌘ and hold only option, scrolling stays stopped.
Note When you scroll with Temporary Override, apps see an ordinary scroll, as if no modifier keys were held. Actions that apps assign to a modifier key plus scrolling (such as zooming) don’t happen.
