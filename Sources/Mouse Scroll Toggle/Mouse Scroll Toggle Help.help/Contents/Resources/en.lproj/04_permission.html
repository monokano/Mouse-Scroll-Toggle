Permissions and Troubleshooting

Allow Mouse Scroll Toggle to control your Mac

To stop scrolling, Mouse Scroll Toggle needs permission to control your Mac. It uses this permission to receive scroll input and stop it. Without it, scrolling can’t be stopped.

When permission is missing, the app lets you know:

  • The menu bar icon changes to a warning triangle. Click it to see a dialog asking for permission.
  • The Dock icon’s menu shows “⚠️ Permission to control your Mac required.” Choose it to see a dialog asking for permission.

Click Open System Settings in the dialog to go straight to the place where you set the permission. To open it yourself, go to the place for your version of macOS:

macOS 26 or earlier
Privacy & Security › Accessibility
macOS 27 or later
Privacy & Security › Device Control and Data Access
  1. Open the place above in System Settings.
  2. Turn on Mouse Scroll Toggle in the list. If it isn’t listed, click the + button and add Mouse Scroll Toggle from the Applications folder.
Note Accessibility in the System Settings sidebar is for settings that help with seeing, hearing, and using your Mac. You set this permission in Privacy & Security, not there.

If something doesn’t work

Scrolling isn’t stopped
Make sure Mouse Scroll Toggle has permission to control your Mac. If Stop Scrolling In is set to Registered Apps, also make sure the app is in the Registered Apps list.
Only one direction is stopped, or a direction you want to keep is stopped
For registered apps, check the buttons at the right end of each row in the Registration tab (see Choosing the directions to stop for each app). If Stop Scrolling In is set to All Apps, check Directions to Stop in the General tab.
The menu bar icon is missing
Display Mode may be set to Dock Only, or the icon may be hidden behind the notch. Hold down Command while opening Mouse Scroll Toggle to reset Display Mode to the default (Menu Bar and Dock).
